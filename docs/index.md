# ShowPFS

**A Chrome extension that annotates Hakfa KPPY text on web pages with the PFS reading — and pops up a built-in Hakkadict entry whenever you select a Hakfa word.**

Hakfa (客家話) is written in two competing Roman orthographies: **KPPY** (教育部客家語拼音方案, the MOE system) and **PFS** (Pha̍k-fa-sṳ / 白話字, the Presbyterian system). MOE dictionaries publish only KPPY; readers familiar with PFS have to translate every entry in their head. ShowPFS does the translation for you, in place — and supplements it with selection-based dictionary lookup, so you can read Hakfa text on any page without bouncing through search forms.

```
hiauˋ dedˋ           →  hiauˋ dedˋ (hiáu-tet)
gonˊ ziinˊnaˇ        →  gonˊ ziinˊnaˇ (kôn-chṳ̂n-nà)
tai kin              →  tai kin (thai-khin)
```

Select any Hakfa text — Hanji like 學得 or any Romanized form — and a small card appears with the matching MOE Hakkadict entry: Si-yen / Nam Si-yen forms, PFS reading, gloss, and an example sentence. The dictionary index ships with the extension; no lookup ever leaves your browser.
